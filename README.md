## zabbix采集管家

> System Version: `lwops V6`

## 概述
一款深度集成于Zabbix 界面的功能扩展插件，主要用于实现Zabbix页面嵌套和API数据查询，以帮助更灵活地整合第三方系统，并增强Zabbix的数据交互能力。

- Zabbix页面无缝嵌套

  - 支持在Zabbix Web界面内直接嵌入第三方系统页面（如运维平台、CMDB、自定义监控面板等），保持统一的用户操作体验。

  - 提供安全的iframe集成方案，支持动态Token鉴权，确保数据访问的安全性。

- 增强型API查询接口

  - 代理Zabbix原生API能力，提供的数据查询接口，支持组合查询、批量获取监控数据，减少API调用次数。

- 权限与Session管理

  - 保持与Zabbix用户权限体系一致，确保嵌套页面和API查询遵循Zabbix RBAC（基于角色的访问控制）。
  - 支持Session共享，避免重复登录，提升用户体验。

## 代码结构

项目采用插件化模式分包，使层级结构更清晰合理，同时有效降低耦合度。。

```
DataCollectionManager
  |-assets == 前端静态定义
  |-commands == 控制台命令定义
  |-components == 组件包 
  |-config == 插件配置目录
  |-controllers == 控制器定义
  |-errors == 错误信息定义
  |-resource == 资源目录（菜单、路由）
  |-services == 服务接口
  |-syncers == UI链接接口
  |-views == 视图目录
```

## 要求
此扩展的最低要求是您的 Web 服务器支持 PHP 7.4。
